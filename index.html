Los 4 Pilares del Clon de GitHub

Combinando diseño Primer de GitHub, rendimiento estático ultrarrápido, contratos deterministas y estándares de agentes de IA.

1. Motor Git Virtual y Persistencia Total

Almacena repositorios, ramas, archivos y commits directamente en el navegador del cliente mediante IndexedDB con fallback automático a localStorage. Cuenta con un comparador de diferencias línea por línea (+ verde / - rojo) y soporte para Forks y Stars.

  • • Árbol de archivos jerárquico con breadcrumbs
  • • Diff viewer visual línea por línea
  • • Respaldo y restauración JSON instantánea

2. Tailwind CSS & HTMX Declarativo

Interfaz pixel-perfect idéntica a GitHub Dark Primer (`#0d1117`) y conmutador a modo claro. Emplea HTMX para swaps y transiciones reactivas de pestañas y modales sin necesidad de compilar frameworks pesados como React o Vue.

  • • 100% código estático nativo sin bundlers
  • • Soporte de enrutamiento SPA con 404.html
  • • Resaltado sintáctico con Highlight.js

3. Knowledge-Driven Development (KDD)

Implementa la metodología de Mauricio Perera que unifica OKF (Open Knowledge Format en Markdown) con CCDD (Contract-Driven Development). Controla determinísticamente a los agentes de IA evaluando presupuestos de complejidad y oráculos de prueba congelados.

  • • Validador de complejidad ciclomática en vivo
  • • Detección de oráculos de prueba y perímetros
  • • Tablero Kanban KDD-Board de 5 etapas

4. FastWebMCP & Estándar webmcp.com

Exposición nativa de 10 herramientas MCP en el objeto global document.modelContext. Permite que navegadores con WebMCP o agentes de IA interactúen con el repositorio a través de APIs imperativas y declarativas.

  • • Playground interactivo de invocación para agentes
  • • Atributos declarativos toolname en formularios
  • • Exportación compatible con webmcp.com
Directorio WebMCP

12 Herramientas Nativas para Agentes

Disponibles en el runtime del navegador para cualquier agente que soporte la especificación WebMCP.

list_repositories read-only

Lista todos los repositorios disponibles en el almacenamiento cliente.

get_repository read-only

Obtiene ramas, descripción y estrellas de un repositorio.

get_file read-only

Lee el contenido de un archivo en una ruta y rama específica.

create_or_update_file mutating

Realiza un commit con cambios a un archivo en la rama indicada.

list_issues read-only

Lista incidencias filtradas por estado (open, closed, all).

create_issue mutating

Publica una nueva incidencia con título, descripción y etiquetas.

create_pull_request mutating

Abre un Pull Request comparando rama origen y destino.

validate_kdd_contract read-only

Ejecuta la validación determinista de un contrato CCDD en el navegador.

get_kdd_board read-only

Obtiene las columnas y tarjetas de tareas del tablero Kanban.

update_kdd_task mutating

Actualiza la etapa de una tarjeta o la asignación de un agente.

trigger_workflow mutating

Dispara una ejecución de CI/CD determinista (KDD Actions) 100% en el navegador.

get_workflow_runs read-only

Inspecciona el historial de ejecuciones de CI y los registros de terminal en tiempo real.

Despliegue Inmediato

Publica en GitHub Pages usando GitHub CLI (gh)

Sube este clon a tu cuenta de GitHub y tenlo online en menos de 60 segundos.

bash / terminal 
# 1. Inicializa el repositorio local
git init
git add .
git commit -m "feat: launch 100% client-side github clone with kdd and webmcp"
git branch -M main

# 2. Crea el repositorio remoto y sube el código con gh CLI
gh repo create webmcp-github --public --source=. --push \
  --description "100% functional client-side GitHub clone deployable to GitHub Pages with Tailwind, HTMX, KDD, and FastWebMCP."

# 3. Habilita GitHub Pages apuntando a la rama main (root)
gh api -X POST "repos/MauricioPerera/webmcp-github/pages" \
  -f "source[branch]=main" -f "source[path]=/"

# 4. Abre el repositorio en tu navegador
gh browse
